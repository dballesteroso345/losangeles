# Cronograma - Grado 11: Proyecto de Innovación Tecnológica

## Información General
- **Materia:** Innovación Tecnológica
- **Enfoque:** Proyecto de grado con enfoque profesional
- **Modalidad:** Proyecto individual o en parejas
- **Duración:** Todo el período de clases

---

## Unidad 1: Investigación y Definición del Problema

### Semana 1-2: Identificación de oportunidades
- Metodologías de innovación (Design Thinking)
- Identificación de problemas reales
- Investigación de necesidades
- **Entregable:** Propuesta de 3 problemas/opportunidades

### Semana 3-4: Validación de idea
- Entrevistas y encuestas
- Análisis de viabilidad técnica
- Definición del problema
- **Entregable:** Documento de validación + problema definido

---

## Unidad 2: Diseño y Arquitectura

### Semana 5-6: Diseño de solución
- Arquitectura del sistema
- Stack tecnológico
- Diagramas (UML, flujo)
- **Entregable:** Documento de arquitectura

### Semana 7-8: Prototipo inicial
- Wireframes y mockups
- Prototipo no funcional
- Validación con usuarios
- **Entregable:** Prototipo validado

---

## Unidad 3: Desarrollo del Proyecto

### Semana 9-10: Setup y base
- Configuración de entorno
- Estructura del proyecto
- Control de versiones (Git)
- **Entregable:** Repositorio inicial + estructura

### Semana 11-12: Desarrollo MVP
- Funcionalidades core
- Backend/API
- Base de datos
- **Entregable:** MVP funcional

### Semana 13-14: Frontend e integración
- Interfaz de usuario
- Integración backend-frontend
- Testing básico
- **Entregable:** Versión alpha

---

## Unidad 4: Cierre y Presentación

### Semana 15-16: Pulido final
- Bug fixing
- Optimización
- Documentación técnica
- **Entregable:** Versión final

### Semana 17-18: Presentación de grado
- Preparación de pitch
- Demostración funcional
- Documentación de proyecto
- Defensa oral
- **Entregable:** Proyecto completo + presentación + documentación

---

## Criterios de Evaluación

| Aspecto | Porcentaje |
|---------|------------|
| Innovación y creatividad | 20% |
| Calidad técnica | 25% |
| Documentación completa | 15% |
| Proceso y metodología | 15% |
| Impacto y utilidad | 10% |
| Presentación y defensa | 15% |

## Áreas de Proyecto Sugeridas

| Área | Tecnologías |
|------|-------------|
| Desarrollo Web | React, Node.js, PostgreSQL |
| Inteligencia Artificial | Python, TensorFlow, APIs |
| Automatización | Python, Selenium, APIs |

---

## Entregables Finales de Grado
1. **Código fuente** en repositorio Git
2. **Documentación técnica** (arquitectura, API, instalación)
3. **Manual de usuario**
4. **Presentación ejecutiva** (10 minutos)
5. **Video demostrativo** (máximo 3 minutos)
6. **Reflexión del proceso** (postmortem)

---

## Competencias Desarrolladas
- Metodología de investigación
- Gestión de proyectos de software
- Desarrollo full-stack
- Comunicación profesional
- Pensamiento crítico y resolución de problemas
