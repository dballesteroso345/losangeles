## OBSERVACIONES GENERALES DE LA PROGRAMACIÓN

**Nota:** Esta programación representa la cumbre del currículo de Innovación Tecnológica, con enfoque en proyecto de grado auténtico con impacto real potencial.

**Recursos Requeridos:**
- Sala de sistemas con computadores adecuados para desarrollo
- Conexión a internet estable para investigación, desarrollo y publicación
- Software según proyectos (varía: herramientas de desarrollo web, mobile, data, etc.)
- Acceso a servicios cloud gratuitos (Firebase, Supabase, Vercel, Netlify, GitHub Student Pack)
- Posible presupuesto pequeño para hosting/domains si proyectos lo requieren

**Evaluación Continua:**
- Rúbricas de proyecto de grado (peso en proceso, no solo producto)
- Entregables: investigación de usuarios, prototipos, MVP, producto final, documentación, presentación
- Evaluación con jurado multidisciplinario
- Énfasis en impacto real y aprendizaje transferible

**Ajustes Razonables:**
- Proyectos individuales o en parejas según complejidad
- Flexibilidad en stack tecnológico según intereses y oportunidades de aprendizaje
- Apoyo intensivo para estudiantes con menos base técnica
- Desafíos adicionales para estudiantes avanzados (escalabilidad, seguridad avanzada, ML)

**Proyección Post-Grado 11°:**
- Estudiantes preparados para educación superior en tecnología o ingreso directo a industria
- Portafolio de proyecto de grado usable para aplicaciones universitarias y empleo
- Posible incubación de proyectos con potencial de impacto real
- Red de ex-alumnos para mentoría continua y colaboración

**Impacto Esperado:**
- 100% de estudiantes completan proyecto funcional
- 50%+ de proyectos tienen usuarios reales fuera del colegio
- 25%+ de proyectos continúan desarrollándose post-grado
- Estudiantes se identifican como "innovadores" y "creadores tecnológicos"
