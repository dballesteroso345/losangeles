## Metodología General

### Para Grados 6°-10° (Videojuegos):

1. **Fase 1 - Ideación (Semanas 1-4):**
   - Brainstorming y análisis de juegos existentes
   - Definición del concepto
   - Documento de diseño inicial

2. **Fase 2 - Diseño (Semanas 5-8):**
   - GDD completo
   - Creación de assets visuales
   - Diseño de niveles

3. **Fase 3 - Desarrollo (Semanas 9-14):**
   - Programación del juego
   - Implementación de mecánicas
   - Integración de assets

4. **Fase 4 - Cierre (Semanas 15-18):**
   - Testing y pulido
   - Publicación en itch.io
   - Presentación final

### Para Grado 11° (Proyecto de Grado):

1. **Fase 1 - Definición (Semanas 1-4):**
   - Identificación del problema
   - Propuesta de proyecto

2. **Fase 2 - Planificación (Semanas 5-8):**
   - Arquitectura y diseño
   - Tecnologías a usar

3. **Fase 3 - Desarrollo (Semanas 9-14):**
   - Implementación
   - Pruebas

4. **Fase 4 - Cierre (Semanas 15-18):**
   - Documentación
   - Presentación final
