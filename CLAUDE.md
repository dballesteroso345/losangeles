# Instrucciones para Claude

## Contexto del Proyecto

Soy profesor de la materia **Innovación Tecnológica** para grados 6° a 11°. Este directorio contiene todo el material de mi curso.

## Estructura del Proyecto

- **grado_6/** a **grado_11/**: Carpetas por cada grado con sus cronogramas
- **README.md**: Documentación completa del proyecto
- **MEMORY.md**: Estado actual y pendientes

## Grados 6° a 10°: Videojuegos

Los estudiantes diseñan y crean un videojuego funcional en grupos de 2 personas. Trabajan durante toda la clase siguiendo el cronograma de cada grado.

**Progresión:**
- 6°: Scratch/MakeCode (básico)
- 7°: GDevelop/Construct 3 (intermedio)
- 8°: Godot + GDScript (intermedio-alto)
- 9°: Godot profesional (avanzado)
- 10°: Godot profesional con mayor profundidad (avanzado)

## Grado 11°: Proyecto de Grado

- Proyecto de grado con enfoque profesional según interés del estudiante

## Cómo Trabajar

1. **Primero:** Lee README.md y MEMORY.md para contexto
2. **Luego:** Revisa el cronograma del grado solicitado
3. **Ayuda con:**
   - Crear materiales y guías
   - Desarrollar rúbricas
   - Preparar presentaciones
   - Resolver dudas técnicas
   - Generar código de ejemplo

## Convenciones

- Los archivos de cronograma están en español
- Usar Markdown para documentación
- Los entregables están marcados en cada semana del cronograma

## Archivos Importantes

| Archivo | Propósito |
|---------|-----------|
| README.md | Contexto completo del proyecto |
| MEMORY.md | Estado actual y pendientes |
| cronograma.md | Plan por semana (en cada carpeta de grado) |

## Al Retomar

Cuando se acaben los tokens y retomes este proyecto:

1. Lee `README.md` primero
2. Revisa `MEMORY.md` para ver el estado actual
3. Pregunta en qué grado y semana estás trabajando
4. Consulta el `cronograma.md` del grado correspondiente
5. Continúa desde donde quedó el trabajo
